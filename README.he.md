# Jarvis Agent

אפליקציית דסקטופ בעברית ל־macOS, Windows ו־Linux, המבוססת על MARK LIV של FatihMakes.

גרסת התצוגה המקדימה כוללת חבילות שנבנו מקומית ל־macOS במעבדי Apple Silicon, ל־Windows x64 ול־Linux x64. אפליקציית macOS הופעלה ונבדקה. חבילות Windows ו־Linux עברו בדיקות מבנה ותלויות; הן טרם הופעלו במערכות האלה. גרסת macOS למעבדי Intel אינה כלולה.

## התקנה

הורד את החבילה המתאימה מהעמוד [Releases](https://github.com/arielaizn/jarvis-agent/releases):

- macOS 14.2 ומעלה: קובץ DMG למעבד Apple Silicon. גרור את האפליקציה לתיקיית Applications.
- Windows: קובץ Setup EXE או חבילת ZIP ניידת. בחבילה הניידת מפעילים את Jarvis Agent.cmd.
- Linux: חבילת TAR.GZ עם Python מובנה. מפעילים את jarvis-agent מתוך התיקייה. הוראות התקנת ספריות המערכת נמצאות ב־readme.md.

החבילות הראשונות מופצות ללא אישור Notarization של Apple וללא חתימת Authenticode של Windows. מערכת ההפעלה עשויה לבקש אישור פתיחה.

## התחלה

התקן Codex CLI והתחבר לחשבון שלך. המודל המוגדר למשימות הוא GPT 6 Astra ברמת High. לקול ולראייה יש להזין בהגדרות מפתח Gemini עם גישה למודל המבוקש. ההתקנה אינה כוללת מפתחות או מנוי לשירותי המודלים.

המיקרופון, המצלמה ושיתוף המסך דורשים הפעלה מפורשת. התקנה נקייה יוצרת תיקיית notes פרטית. לחיבור תיקייה אחרת, הגדר את notes_dir בקובץ config.json המקומי לפני הפעלת השרת.

## קול וחלונית עבודה

רעש ושיחה ברקע עוברים סינון לפני תגובה. פנייה בשם ״ג׳רוויס״ ואחריה בקשה מתקבלת מיד. בקשות בלי השם נבדקות באמצעות TypeSafe כשהמפתח שלו מוגדר. אם השירות אינו זמין, אפשר לפנות בשם. הסינון עובד על התמלול ואינו מזהה את האדם שדיבר.

במשימת מחשב שמציינת תוכנה נתמכת, ג׳רוויס מביא אותה לחזית ועובר לחלונית צפה עם זמן והתקדמות מהשרת. יש כפתורי עצירה וחזרה לממשק. לחיצה כפולה על החלונית מחזירה את החלון המלא. הכפתורים ״פנים״ ו״ליבה״ מחליפים בין שתי התצוגות.

## משימות במקביל

עד 3 סוכנים פעילים ועד 12 בקשות שהתקבלו. אמור ״סוכן רקע: ...״ או בחר סוכן רקע ליד שורת ההקלדה. לכל משימה יש מצב, תשובה וכפתור עצירה.

סוכני הרקע עוסקים במחקר וניתוח. פעולות במחשב ושינוי קבצים עוברים בתור משותף. החלפת ספק עוצרת את המשימות הפעילות.

## מגבלות ותלויות

מעקב ריכוז אחר היישום הקדמי ומארח הלשונית ממומש כרגע ב־macOS. החבילות של Windows ו־Linux אינן מציגות את התכונה הזו כנתמכת. שליטה בתוכנות עריכה תלויה בממשק של התוכנה ובהרשאות מערכת ההפעלה.

Browser-use דורש סביבת Python נפרדת ודפדפן. זמינות המודלים והמכסה תלויות בחשבון שלך. מזהה מודל שאינו נגיש יפיק שגיאה.

המפתחות, ההערות והזיכרון נשמרים בתיקיית המשתמש. הם אינם נכללים בקוד המקור או בהתקנה. מיקומי התיקיות והוראות הבנייה מופיעים ב־readme.md.

לפני מסירת שינוי, הרץ preflight.py מול המערכת המוגדרת. הוא מבצע קריאות אמיתיות ומחזיר כישלון גם במקרה של חוסר מכסה.
