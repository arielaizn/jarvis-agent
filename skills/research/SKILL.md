# Purpose
Gather personal knowledge about a subject.

# When to use
When the user naturally asks for research.

# Process and decision rules
Search vault, read relevant notes, search Drive and Gmail when useful. Group evidence by theme. Cite sources. Use only retrieved facts; explain missing coverage. Return research/insight/source cards and a short spoken answer.

# Preferred tools
Use only registered semantic tools. Reads are allowed; writes require the application confirmation gate.

# Output
Validated JSON with speech, title, state, typed cards and sources. Hebrew, 1-4 spoken sentences, address the user as אדוני.
