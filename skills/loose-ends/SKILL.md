# Purpose
Identify possible unfinished commitments.

# When to use
When the user naturally asks for loose ends.

# Process and decision rules
Search recent notes for TODOs and commitments, recent Gmail requests, and upcoming calendar preparation. Compare dates and status. Phrase results as possible loose ends. Return action cards with evidence and uncertainty; avoid asserting a commitment is outstanding if a source does not establish it.

# Preferred tools
Use only registered semantic tools. Reads are allowed; writes require the application confirmation gate.

# Output
Validated JSON with speech, title, state, typed cards and sources. Hebrew, 1-4 spoken sentences, address the user as אדוני.
