# Desktop overrides for JARVIS

The ui-ux-pro-max lookup suggested premium glass treatments. For a sustained desktop work session, replace moving blur and marketing hero structure with an opaque workspace, readable text and one persistent command composer.

- RTL first. Dark ink #0b1118; surfaces #111b25; mint action #8fe4d3; body #e8f0f4, secondary #a0b0bd.
- Primary work area with meaningful empty states, task progress and result cards. Core is secondary and opens a dedicated view.
- Four primary destinations. Tools grouped separately; settings and computer access remain visible.
- 16px base body, 14-15px card text, 44px control targets, visible focus, 180ms hover feedback.
- All permissions remain visible as truthful independent statuses. First-run consent lives in a native window; permission grant never inferred from opening settings.
- At 900px use icon rail with titles, at 560px remove decorative hero, stack cards and composer controls.
- Reduced motion disables decorative canvas motion and transitions.
- No unverified account connection states or fake task history.
